01

What is PHP?

The foundation — what PHP actually is, where it runs, and why it exists.

PHP stands for "PHP: Hypertext Preprocessor" (a recursive acronym). It is a widely-used, open-source, server-side scripting language designed specifically for building dynamic and interactive websites. PHP code is written inside HTML pages but is executed entirely on the server, before anything is sent to the visitor's browser.

In one line: PHP takes a request from a browser, runs some logic on the server (talk to a database, do calculations, check a login), and sends back plain HTML — the browser never sees the PHP code itself.

A short history

  • Created in 1994 by Rasmus Lerdorf as a small set of tools called "Personal Home Page" scripts.
  • Evolved into a full scripting language and was re-branded as PHP: Hypertext Preprocessor.
  • PHP 7 (2015) brought major speed improvements; PHP 8.x is the current modern generation with features like JIT compilation, union types, and the match expression.
  • It powers a huge share of the web — including WordPress, large parts of Facebook's original codebase, and Wikipedia.

Why developers use PHP

  • Free and open-source — no licensing cost.
  • Cross-platform — runs on Windows, macOS, and Linux.
  • Easy to learn — simple syntax, very close to C/JavaScript style.
  • Database friendly — built-in support for MySQL, PostgreSQL, SQLite and more.
  • Huge ecosystem — frameworks like Laravel, Symfony, and CMS platforms like WordPress are all built on PHP.
  • Embeds directly into HTML — you can mix PHP logic and HTML markup in the same file.

Client-side vs. server-side — where PHP actually runs

This is the single most important idea to understand before writing any PHP. A web page can involve two different places where code executes:

ConceptServer-side (PHP)Client-side (HTML / CSS / JavaScript)
Where it runsOn the web serverInside the visitor's browser
Who can see the codeNobody — the visitor only receives the resultAnyone — visible via "View Source" / DevTools
Typical usesDatabases, authentication, business logic, file handlingAnimations, form validation, interactivity, DOM updates
File extension.php.html / .css / .js

Here is the request lifecycle for a PHP-powered page, step by step:

  1. Your browser sends a request for a page, e.g. profile.php.
  2. The web server (Apache/Nginx) sees the .php extension and hands the file to the PHP engine instead of sending it directly.
  3. The PHP engine runs every block wrapped in <?php ... ?>, executing logic, pulling data from a database if needed.
  4. PHP produces plain HTML as output and hands it back to the server.
  5. The server sends that finished HTML to the browser — the browser renders it like any normal web page, with no idea PHP was ever involved.
Tip: If you "View Page Source" on a working PHP website, you will only ever see the generated HTML — never the PHP code. That's proof it already ran on the server.
02

How to Install & Run PHP

PHP files can't just be double-clicked — you need something that understands the .php extension and runs the engine. Here are the three common paths.

Option A — All-in-one local server stacks (best for beginners)

These bundle a web server (Apache), a database (MySQL), and PHP together so you don't configure anything by hand.

ToolPlatformNotes
XAMPPWindows / macOS / LinuxMost popular, from apachefriends.org
WAMPWindows onlyWindows + Apache + MySQL + PHP
MAMPmacOS (and Windows)Mac + Apache + MySQL + PHP
LAMPLinuxUsually installed via apt as separate packages
  1. Download XAMPP from apachefriends.org and run the installer.
  2. Open the XAMPP Control Panel and click Start next to Apache.
  3. Place your project folder inside XAMPP's htdocs directory (e.g. C:\xampp\htdocs\myproject).
  4. Open a browser and visit http://localhost/myproject/index.php — PHP runs and the result is rendered.

Option B — Install PHP directly + built-in dev server (great for practice)

PHP ships with a lightweight built-in server, so you don't need Apache at all while learning.

OSInstall command
WindowsDownload from php.net/downloads, add the folder to your PATH
macOSbrew install php
Linux (Debian/Ubuntu)sudo apt install php
  1. Verify the install: php -v — should print the installed PHP version.
  2. Run a single script directly in the terminal (no browser needed): php hello.php — this is called CLI mode and prints straight to the terminal.
  3. Or start a local dev server for a whole folder: php -S localhost:8000, then open http://localhost:8000 in your browser.

Option C — Online PHP editors (zero install)

Useful for quick experiments without installing anything: sites like 3v4l.org (test across multiple PHP versions at once), onlinephp.io, and replit.com all let you write and run PHP in the browser.

Verifying your setup

Create a file called info.php with the single line below, place it in your server root, and open it in the browser. It prints a full page with your PHP version, loaded extensions, and configuration — the standard "it's alive" check.

info.php
<?php
phpinfo();
?>
Note: phpinfo() needs a real PHP engine (Options A or B above) — the playground on this page is a simplified simulator built in JavaScript, so this particular command isn't runnable here. Everything else on this page is.

Recommended editor

Any text editor works, but VS Code with the PHP Intelephense extension gives you autocomplete, error checking, and formatting for free.

03

Basic Syntax — Your First Program

The rules every PHP file follows, plus your first runnable "Hello, World!".

  • PHP code always lives between <?php and ?> tags. Anything outside these tags is treated as plain HTML and sent through untouched.
  • Every statement ends with a semicolon ;.
  • The most common way to output content is the echo keyword (or print).
  • PHP is case-sensitive for variables ($Name and $name are different) but keywords and function names are not case-sensitive (ECHO, Echo, and echo all work — though lowercase is standard style).
  • If a file contains only PHP code, the closing ?> tag is usually omitted — it avoids accidental blank-line output.

Hello, World!

hello.php 
<?php
echo "Hello, World!";
?>

05
Variables

        
Named containers that hold data your program works with.


        
    
          
  • Every variable name starts with a dollar sign $, e.g. $age.
    • 
          
  • After the $, the name must start with a letter or underscore, followed by letters, numbers, or underscores (no spaces, no starting with a digit).
    • 
          
  • Variable names are case-sensitive: $total and $Total are two different variables.
    • 
          
  • PHP is loosely typed (also called dynamically typed) — you never declare a type up front; PHP figures it out from the value you assign.
    • 
          
  • Assign a value with the = operator.
    • 
        


        

          
variables.php

          
<?php
$name = "Priya";
$age = 22;
$isStudent = true;

echo "Name: $name\n";
echo "Age: $age\n";
?>

          
Output

staticA local variable that remembers its value between function calls

          

        

        
Tip: Inside a function, PHP does not automatically see outer/global variables — you must use the global keyword or pass the value as a parameter.

Data Types — The Two Main Categories

        
PHP's data types split cleanly into two big sets: values that hold one single piece of data, and values that hold collections of other data.


        
PHP organizes its data types into two major groups:


        

          

            
SET 1 · Scalar types

            
Hold exactly one single value.

            int    → 42, -7, 1000
            float  → 3.14, 0.5
            string → "hello", 'PHP'
            bool   → true, false
          

          

            
SET 2 · Compound types

            
Hold collections of other values.

            array  → [1, 2, 3]
            object → instance of a class
          

        


        
Plus two special types you'll see occasionally: NULL (a variable with no value at all) and resource (a reference to an external resource, like an open file or database connection). They don't fit neatly into either main set, but every value in PHP belongs to one of these four groups overall.


        

          

            
TypeCategoryExampleDescription

            
intScalar$x = 10;Whole numbers, positive or negative

            
floatScalar$x = 9.81;Decimal / floating-point numbers

            
stringScalar$x = "Hi";Text, in single or double quotes

            
boolScalar$x = true;Only two values: true or false

            
arrayCompound$x = [1,2,3];An ordered map of keys to values

            
objectCompound$x = new Car();An instance created from a class

            
NULLSpecial$x = null;Represents "no value"

            
resourceSpecialfopen(...)Handle to an external resource

          

        


        
Checking and converting types

        
Because PHP decides types automatically, it also gives you tools to inspect or force them:

        
    
          
  • gettype($x) — returns the current type as a string.
    • 
          
  • var_dump($x) — prints the type and the value, useful for debugging.
    • 
          
  • Type casting — force a value into another type: (int)$x, (float)$x, (string)$x, (bool)$x, (array)$x.
    • 
          
  • Type juggling — PHP automatically converts types in certain operations, e.g. comparing "100" > $intVal converts the numeric string "100" into a number before comparing.
    • 
        


        

          
types.php

          
<?php
$intVal = 15;
$floatVal = 3.5;
$strVal = "PHP";

echo "sum: " . ($intVal + $floatVal) . "\n";
echo "juggling: " . (("100" > $intVal) ? "yes, 100 wins" : "no") . "\n";
echo "concat: " . $strVal . " rocks\n";
?>

Constants

        
Values that, once set, never change for the rest of the script.

        
    
          
  • Defined with define('NAME', value) or the const keyword.
    • 
          
  • By convention, constant names are written in UPPERCASE.
    • 
          
  • No $ sign is used when referring to a constant.
    • 
          
  • Cannot be reassigned once defined — attempting to will trigger an error.
    • 
        

        

          
constants.php

          
<?php
define("SITE_NAME", "MyBlog");
const MAX_USERS = 100;

echo SITE_NAME . " allows up to " . MAX_USERS . " users.";
?>

Operators

        
Symbols that perform actions on values and variables.


        

          

            
CategoryOperatorsExample

            
Arithmetic+  -  *  /  %  **$a + $b, $a % $b (remainder)

            
Assignment=  +=  -=  *=  /=  .=$x += 5; // same as $x = $x + 5

            
Comparison==  ===  !=  !==  <  >  <=  >=$a === $b (equal value AND type)

            
Logical&&  ||  !  and  or$a > 0 && $b > 0

            
String.  .="Hi " . $name

            
Increment / Decrement++  --$i++;  $i--;

            
Null coalescing??$name = $input ?? "Guest";

          

        


        
== vs === — == compares only the value (loose comparison, allows type juggling); === compares value and type (strict comparison). "5" == 5 is true, but "5" === 5 is false. Prefer === to avoid surprises.


        

          
operators.php

          
<?php
$a = 10;
$b = 3;

echo "Add: " . ($a + $b) . "\n";
echo "Remainder: " . ($a % $b) . "\n";
echo "Loose (==): ";
if ("10" == $a) { echo "true\n"; } else { echo "false\n"; }
echo "Strict (===): ";
if ("10" === $a) { echo "true\n"; } else { echo "false\n"; }
?>

OOP Basics — Classes & Objects

        
PHP is not only procedural — it also supports Object-Oriented Programming, built around two core ideas: classes (blueprints) and objects (instances made from that blueprint).


        

          

            
TermMeaning

            
classA blueprint describing properties (data) and methods (behavior)

            
objectA real instance created from a class, using new

            
$thisRefers to the current object inside its own methods

            
__construct()A special method that runs automatically when an object is created

            
extendsLets one class inherit properties/methods from another

          

        


        
Access modifiers (brief): public — accessible from anywhere · protected — accessible inside the class and its subclasses · private — accessible only inside the class itself.


        
Defining a class and creating an object

        

          
car.php

          
<?php
class Car {
  public $brand;
  public $speed = 0;

  public function __construct($brand) {
    $this->brand = $brand;
  }

  public function accelerate($amount) {
    $this->speed += $amount;
  }

  public function describe() {
    return "$this->brand is going {$this->speed} km/h";
  }
}

$myCar = new Car("Tesla");
$myCar->accelerate(40);
echo $myCar->describe();
?>

        

        
Reference-only example: object-oriented code needs a real PHP engine to execute (this page's simulator handles procedural PHP only). Copy this into XAMPP or an online PHP editor from Section 02 to see it run — the expected output is Tesla is going 40 km/h.
