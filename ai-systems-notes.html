7 Types of Intelligent Agents

In AI, an agent perceives its environment through sensors and acts upon it through actuators. What separates the seven classes is how much the agent remembers, plans, and improves.

1. Simple Reflex Agent

Simple Reflex Agent

DefinitionSelects an action based only on the current percept, ignoring percept history, using condition–action rules ("if condition, then action").

2. Model-Based Reflex Agent

Model-Based Reflex Agent

DefinitionMaintains an internal state/model representing unobserved parts of the world, combining current percepts with world memory.

3. Goal-Based Agent

Goal-Based Agent

DefinitionChooses actions by considering future consequences against an explicit goal, using search or planning algorithms.

4. Utility-Based Agent

Utility-Based Agent

DefinitionPicks action sequences that maximize a utility function (trade-off score for speed vs. cost vs. safety).

5. Learning Agent

Learning Agent

DefinitionImproves performance over time using Performance Element, Critic, Learning Element, and Problem Generator.

6. Multi-Agent System (MAS)

Multi-Agent System

DefinitionTwo or more autonomous agents cooperating or competing in a shared environment (e.g. CrewAI, AutoGen).

7. Hierarchical Agent

Hierarchical Agent

DefinitionOrganizes decision-making into strategic manager, tactical planner, and execution reflex layers.

02

Model Classes — LLM, VLM, SLM, MLM, LCM

LLM Large Language Model

Transformer-based decoder models trained on massive text corpora (e.g. GPT-4, Claude, LLaMA 3).

VLM Vision-Language Model

Jointly processes images and text in a shared embedding space (e.g. CLIP, LLaVA, GPT-4V).

SLM Small Language Model

Compact models (1B–8B params) optimized for edge & on-device efficiency (e.g. Phi-3, Gemma).

MLM Masked Language Model

Fill-in-the-blank bidirectional representation models (e.g. BERT, RoBERTa).
