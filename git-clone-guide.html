Git · beginner guide

Clone a repository the right way.

Cloning copies a remote Git repository — every file and its full commit history — onto your own computer. One command, one download, and you have a working local copy.

Desktop — powershell
PS Desktop>
01 / What cloning does

A copy, not a link

Once cloned, the project lives fully on your machine. You can read files, inspect history, and make commits offline — the remote is only contacted again when you push or pull.

Remote repository
GitHub, GitLab, etc.
git clone
Your computer
Full local copy
git pull
Stay in sync
Later, whenever
02 / Step by step

Six steps, start to finish

Run these in order the first time you clone a project. After that, most days you'll only need git pull.

1
Copy the repository URL
Open the repository you want and copy its HTTPS URL. It looks like https://example.com/username/project.git.
2
Open a terminal in the right folder
Navigate to where you want the project to live before cloning.
cd Desktop
3
Run git clone
Git downloads every file and the entire commit history.
git clone https://example.com/username/student-management.git
4
Move into the project
A new folder is created automatically, named after the repository.
cd student-management
5
Confirm it worked
A clean status means the clone succeeded and you're tracking the remote's main branch.
git status
6
Edit, commit, and push as usual
From here it's the standard cycle: change files, stage them, commit, then push.
git add . git commit -m "Updated student application" git push
!
You only clone once — the first time you get the project. Every time after that, use git pull to bring in the latest changes instead of cloning again.

04 / Quick reference

Commands you'll actually reuse

CommandWhat it does
git clone URLDownloads a remote repository and its full history into a new folder
cd folderMoves your terminal into that folder
git statusShows what's changed, staged, or untracked
git add .Stages every changed file for the next commit
git commit -m "..."Saves the staged changes as a new point in history
git pushUploads your commits to the remote repository
git pullDownloads and merges the latest remote changes
git restore fileDiscards uncommitted changes to a file
