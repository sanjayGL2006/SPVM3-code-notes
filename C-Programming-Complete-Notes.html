Algorithm (Definition & 5 Core Characteristics)

An algorithm is a finite sequence of unambiguous, step-by-step instructions designed to accomplish a specific computational goal.

5 Core Characteristics of a Good Algorithm

  • 1. Input: Receives zero or more well-defined inputs.
  • 2. Output: Produces at least one verified result.
  • 3. Definiteness: Each step is clear, precise, and unambiguous.
  • 4. Finiteness: Must terminate after a countable number of execution steps.
  • 5. Effectiveness: Every operation must be feasible and practically executable.

Sample Algorithm: Add Two Numbers

Step 1: Start
Step 2: Read values A and B
Step 3: Compute S = A + B
Step 4: Display result S
Step 5: Stop

1.5

Find Largest of Three Numbers

Algorithm:
Step 1: Start
Step 2: Read A, B, and C
Step 3: If A >= B and A >= C, then Largest = A
Step 4: Else if B >= C, then Largest = B
Step 5: Else Largest = C
Step 6: Display Largest
Step 7: Stop
largest_three.c 
#include <stdio.h>

int main() {
    int a, b, c;

    printf("Enter three numbers: ");
    scanf("%d %d %d", &a, &b, &c);

    if (a >= b && a >= c)
        printf("Largest = %d\n", a);
    else if (b >= a && b >= c)
        printf("Largest = %d\n", b);
    else
        printf("Largest = %d\n", c);

    return 0;
}
Enter three numbers: 25 48 31 Largest = 48

Sum of First N Natural Numbers

Overview & Features of C

C is a general-purpose, structured programming language created by Dennis Ritchie at Bell Labs in 1972. Evolved from BCPL and B, C was used to re-implement the UNIX Operating System kernel, making it the bedrock of modern software engineering.

12 Hallmark Features of C

1. Simple & Structured

Modular function blocks and clean, uncluttered syntax.

2. Highly Portable

Compiles across multiple hardware CPUs with minimal changes.

3. Fast & Efficient

Near assembly-level speed with minimal memory overhead.

4. Middle-Level Language

Combines high-level abstraction with low-level bit memory manipulation.

5. Pointer Power

Direct access to hardware memory addresses via raw pointers.

6. Rich Operator Set

Over 40 operators including bitwise shifts, logic, and arithmetic.

C Character Set & Tokens

A token is the smallest individual meaningful element of a C program:

                         C TOKENS
                            │
     ┌─────────────┬────────┼─────────────┬─────────────┐
     ▼             ▼        ▼             ▼             ▼
 Keywords    Identifiers  Constants   Operators   Special Symbols
 (int, return) (marks, a)  (10, "Hi")   (+, ==)      ([ ], ;, {})

Rules for Identifiers

  • Can contain letters (a-z, A-Z), digits (0-9), and underscore (_).
  • Cannot begin with a digit (e.g. student1 is valid; 1student is invalid).
  • Cannot contain spaces or special punctuation characters.
  • Cannot be a reserved keyword (e.g. int float; is illegal).
  • C is strictly case-sensitive (total, Total, and TOTAL are three distinct identifiers).

1.12

Standard C Header Files

  • <stdio.h>: Standard I/O (printf, scanf, getchar, puts).
  • <math.h>: Mathematical computations (sqrt, pow, sin, cos, log). Must link with -lm in Linux GCC.
  • <string.h>: String manipulation (strlen, strcpy, strcmp, strcat).
  • <ctype.h>: Character classification (isalpha, isdigit, toupper, tolower).
  • <conio.h>: Legacy Non-standard header (used in Turbo C for clrscr() and getch(); omitted in modern standard ANSI/GCC C).

2.2

Unformatted I/O & Why gets() is Obsolete

Unformatted I/O functions move raw characters without format string parsing:

  • getchar(): Reads a single character from the input stream.
  • putchar(ch): Writes a single character directly to the display.
  • puts(str): Displays a null-terminated string and automatically appends a newline (\n).
Critical Exam Warning on gets()

gets() was officially removed from the C11 standard because it has no buffer boundary limit check, creating critical buffer overflow security vulnerabilities. Modern secure C code strictly uses fgets(buffer, sizeof(buffer), stdin); instead.

C Operators (Arithmetic, Relational, Logical, Bitwise)

1. Pre-Increment vs Post-Increment

FeaturePre-Increment (++a)Post-Increment (a++)
Evaluation OrderIncrements first, then produces the updated value.Produces current value first, then increments.
Example Codeint a=5; int b=++a; ➔ a=6, b=6int a=5; int b=a++; ➔ a=6, b=5

2. Bitwise Operators Walkthrough

Let a = 5 (binary 0101) and b = 3 (binary 0011):
a & b (AND) ➔ 0101 & 0011 = 0001 (Decimal 1)
a | b (OR) ➔ 0101 | 0011 = 0111 (Decimal 7)
a ^ b (XOR) ➔ 0101 ^ 0011 = 0110 (Decimal 6)
~a (NOT) ➔ ~0101 = -6 (2's complement inverted)
a << 1 (Left Shift) ➔ 0101 << 1 = 1010 (Decimal 10, a × 2)
a >> 1 (Right Shift) ➔ 0101 >> 1 = 0010 (Decimal 2, a ÷ 2)

Decision Making (if, if-else, switch-case)

menu_switch.c 
#include <stdio.h>

int main() {
    int choice, a = 10, b = 5;

    printf("1. Add  2. Subtract\nEnter choice: ");
    scanf("%d", &choice);

    switch (choice) {
        case 1:
            printf("Result = %d\n", a + b);
            break;
        case 2:
            printf("Result = %d\n", a - b);
            break;
        default:
            printf("Invalid choice\n");
    }

    return 0;
}
1. Add 2. Subtract Enter choice: 1 Result = 15

2.7

Jump Statements (break, continue, goto)

  • break;: Immediately exits the nearest enclosing loop or switch.
  • continue;: Aborts remaining statements in the current iteration and jumps directly to the loop condition/update.
  • goto label;: Unconditional jump to a labeled statement. Discouraged in structured programming due to spaghetti code.

Contiguous vs Shared Memory
3.1

One-Dimensional Array & Memory Layout

An array is a fixed-size collection of homogenous elements (same data type) stored sequentially in contiguous memory blocks:

Index:        0      1      2      3      4
            ┌──────┬──────┬──────┬──────┬──────┐
Array a:    │  10  │  20  │  30  │  40  │  50  │
            └──────┴──────┴──────┴──────┴──────┘
Address:     1000   1004   1008   1012   1016   (Assuming 4-byte int)

Address Formula: Address of a[i] = Base Address + i × sizeof(data_type)
array_sum.c 
#include <stdio.h>

int main() {
    int a[5] = {10, 20, 30, 40, 50};
    int i, sum = 0;

    for (i = 0; i < 5; i++) {
        sum += a[i];
    }

    printf("Sum = %d\n", sum);
    return 0;
}
Sum = 150

Two-Dimensional Array (Matrix & Row-Major Order)

A 2D array coordinates rows and columns. In C, 2D arrays are flattened in physical memory in Row-Major Order (Row 0 followed immediately by Row 1):

Row 1:  [ 4, 5, 6 ]

Structures (Definition, Dot Operator & Records)

A structure is a user-defined compound type that bundles logically related variables of different data types together under a single name:

student_struct.c 
#include <stdio.h>

struct Student {
    int roll;
    char name[30];
    float marks;
};

int main() {
    struct Student s = {101, "Sanjay", 92.5};

    printf("Roll: %d\n", s.roll);
    printf("Name: %s\n", s.name);
    printf("Marks: %.1f\n", s.marks);

    return 0;
}
Roll: 101 Name: Sanjay Marks: 92.5
3.4

Unions & Structure vs Union Comparison

A union groups heterogeneous members that share the exact same memory location. The total size equals the size of its largest member:

ParameterStructureUnion
Memory AllocationEach member receives its own dedicated memory offset.All members share the same starting memory block.
Total SizeSum of sizes of all members (plus padding alignment).Size of the largest member.
Simultaneous AccessAll members can hold independent values at the same time.Only one member can hold a meaningful value at any instant.

4.1

Pointers (Address Operator & Dereferencing)

A pointer is a variable whose value is the raw physical memory address of another variable:

Variable x:
┌─────────────────────────┐
│ Value = 10              │  Address: 0x7ffd1000
└─────────────────────────┘
             ▲
             │ stores address
Pointer p:   │
┌─────────────────────────┐
│ Value = 0x7ffd1000      │  Address: 0x7ffd1008
└─────────────────────────┘
pointer_demo.c 
#include <stdio.h>

int main() {
    int x = 10;
    int *p = &x;

    printf("Value of x = %d\n", x);
    printf("Address of x = %p\n", (void*)&x);
    printf("Pointer p holds = %p\n", (void*)p);
    printf("Dereferenced *p = %d\n", *p);

    return 0;
}
Value of x = 10 Address of x = 0x7ffeefbff568 Pointer p holds = 0x7ffeefbff568 Dereferenced *p = 10
4.2

Pointer Arithmetic & Scaling Factor

When you perform p++ or p + 1 on a pointer, the address increments by 1 × sizeof(data_type) bytes, pointing directly to the next contiguous element.

4.3

User-Defined Functions (Declaration, Call & Definition)

Functions modularize programs into reusable subroutines:

1. Function Prototype:  int add(int, int);       ➔ Tells compiler signature
2. Function Call:       result = add(10, 20);    ➔ Passes arguments & transfers control
3. Function Definition: int add(int a, int b) {  ➔ Executes algorithm & returns value
                            return a + b;
                        }
4.4

The 4 Categories of User-Defined Functions

1. No Arguments, No Return
void display() { printf("Hi"); }

Performs an action purely via side-effects without passing data.

2. With Arguments, No Return
void add(int a, int b) { printf("%d", a+b); }

Accepts inputs from the caller but directly prints output.

3. No Arguments, With Return
int getNum() { return 50; }

Gathers or computes data independently and returns result to caller.

4. With Arguments, With Return
int add(int a, int b) { return a + b; }

Standard pure functional form: accepts inputs, computes, and returns output.
