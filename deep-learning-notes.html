UNIT 01

Fundamentals of Deep Learning

Where deep learning sits relative to AI and ML, and why it only became practical in the last decade or so.

Definition of Deep Learning

DefinitionDeep Learning is a subset of Machine Learning that uses neural networks with many stacked layers ("deep" networks) to automatically learn hierarchical representations of data, instead of relying on hand-crafted features.
ExampleTo recognise a cat in a photo, a classical ML pipeline needs someone to hand-code "edge detector", "whisker detector" features. A deep network learns edges in layer 1, textures in layer 2, shapes in layer 3, and "cat-like parts" in layer 4 — entirely from data.

AI vs Machine Learning vs Deep Learning

DefinitionAI is the broad goal of building machines that act intelligently. ML is a subfield of AI where systems learn patterns from data instead of being explicitly programmed. Deep Learning is a subfield of ML that specifically uses multi-layer neural networks.
LayerWhat it isExample
Artificial IntelligenceAny technique that makes software behave intelligentlyRule-based chess engine
Machine LearningLearns a function from labelled/unlabelled dataDecision tree, SVM, linear regression
Deep LearningLearns via multi-layer neural networksCNN for image recognition, Transformer for text

Evolution & history of neural networks

DefinitionNeural networks trace back to the 1958 Perceptron, hit a wall after Minsky & Papert (1969) proved single-layer perceptrons cannot solve XOR, revived with backpropagation (1986), and exploded in 2012 when AlexNet won ImageNet using GPUs — the moment "deep learning" became mainstream.
  • 1958 — Rosenblatt's Perceptron, the first trainable artificial neuron.
  • 1986 — Rumelhart, Hinton & Williams popularise backpropagation.
  • 1998 — LeCun's LeNet-5 reads handwritten digits (early CNN).
  • 2012 — AlexNet halves ImageNet error using GPUs and ReLU.
  • 2017 — "Attention Is All You Need" introduces the Transformer.
  • 2020s — GPT-style LLMs, diffusion image models, multimodal agents.

Why Deep Learning became popular

DefinitionThree factors converged: (1) big data — the internet produced millions of labelled images/text, (2) compute — GPUs made matrix multiplication cheap and parallel, (3) algorithms — ReLU, dropout, batch norm and Adam made very deep networks trainable.

Applications, advantages & limitations

DefinitionApplications span vision (face unlock), language (translation, chatbots), audio (voice assistants), healthcare (tumour detection), and recommendation systems.
AdvantagesLimitations
Learns features automaticallyNeeds large labelled datasets
Scales well with more data/computeComputationally expensive to train
State of the art on vision, text, speechActs as a "black box" — hard to interpret
Transfers across tasks (transfer learning)Sensitive to bias in training data

Deep Learning workflow & traditional programming vs ML vs DL

DefinitionTraditional programming: rules + data → output. Machine Learning: data + output → learned rules (model). The DL workflow is the practical loop: collect data → preprocess → design a network → train with backprop → evaluate → tune → deploy → monitor (fully expanded in Unit 25).
UNIT 02

Mathematical Foundations

The four pillars every neural network stands on: linear algebra (data representation), calculus (learning), probability (uncertainty), and statistics (summarising data).

Scalars, vectors, matrices & tensors

DefinitionA scalar is a single number (0-D). A vector is a 1-D array of numbers. A matrix is a 2-D grid of numbers. A tensor generalises this to any number of dimensions — the object every deep learning framework actually computes with.
ExampleA single RGB image is a rank-3 tensor of shape (height, width, 3); a batch of 32 such images is a rank-4 tensor (32, height, width, 3).
import numpy as np

scalar = np.array(5)                  # rank 0
vector = np.array([1, 2, 3])          # rank 1, shape (3,)
matrix = np.array([[1,2],[3,4]])   # rank 2, shape (2,2)
tensor = np.random.rand(32,64,64,3)  # rank 4 image batch
print(matrix.shape, tensor.shape)

Matrix operations — multiplication, transpose, inverse

DefinitionMatrix multiplication combines two matrices into one by summing products of rows and columns — it is literally what "a layer" computes (output = input · weights + bias). Transpose flips rows/columns. Inverse is the matrix that undoes a transformation.
W = np.array([[0.2, 0.8], [0.5, 0.1]])
x = np.array([1.0, 2.0])
y = W @ x                 # matrix-vector multiplication → one dense layer
W_T  = W.T               # transpose
W_inv = np.linalg.inv(W) # inverse (used in solving linear systems, PCA, etc.)

Eigenvalues & eigenvectors

DefinitionAn eigenvector of a matrix is a direction that the matrix only stretches or shrinks (never rotates); the eigenvalue is the amount of stretch. Used in PCA for dimensionality reduction and in understanding how gradients propagate.

Derivatives, partial derivatives, chain rule & gradients

DefinitionA derivative measures how fast a function's output changes as its input changes. A partial derivative does this for one variable while holding others fixed. The chain rule computes the derivative of a composed function by multiplying the derivatives of each step — this is exactly how backpropagation works. A gradient is the vector of all partial derivatives, pointing in the direction of steepest increase.
ExampleIf y = f(g(x)), then dy/dx = f'(g(x)) · g'(x). A network is a long chain of functions (layers), so backprop is just the chain rule applied layer by layer, back to front.

Optimization basics

DefinitionOptimization is the process of adjusting parameters to minimise a loss function. In deep learning this is almost always gradient-based: compute the gradient of the loss with respect to each weight, then nudge the weight slightly against that gradient (covered fully in Unit 6).

Probability, mean/variance/std, distributions, conditional probability & Bayes' theorem

DefinitionMean is the average value; variance/standard-deviation measure spread. A probability distribution describes how likely each outcome is (e.g. Softmax output is a probability distribution over classes). Conditional probability P(A|B) is the chance of A given B already happened. Bayes' theorem, P(A|B) = P(B|A)P(A)/P(B), lets you flip that around — the basis of Naive Bayes classifiers and Bayesian hyperparameter search.
data = np.array([2,4,4,4,5,5,7,9])
mean = data.mean()          # 5.0
variance = data.var()       # average squared distance from the mean
std = data.std()            # sqrt(variance) — same units as the data
UNIT 03

Neural Network Fundamentals

From one biological neuron to a trainable artificial network — the core loop every deeper architecture (CNN, RNN, Transformer) reuses.

Biological vs artificial neuron & the Perceptron

DefinitionA biological neuron receives electrical signals through dendrites, sums them, and "fires" if the sum crosses a threshold. An artificial neuron copies this: it multiplies each input by a weight, adds a bias, sums the result, and passes it through an activation function. The Perceptron (1958) is the simplest such neuron, used for binary classification.
ExampleA perceptron deciding "should I carry an umbrella?" might weight "rain forecast %" heavily and "wind speed" lightly, sum them with a bias, and output 1 (yes) or 0 (no).
def perceptron(x, w, b):
    z = np.dot(w, x) + b        # weighted sum + bias
    return 1 if z > 0 else 0   # step activation

x = np.array([0.9, 0.2])   # [rain %, wind]
w = np.array([2.0, 0.3])
print(perceptron(x, w, b=-1.0))  # → 1 (carry umbrella)

Neural network architecture: input, hidden and output layers

DefinitionThe input layer holds the raw features. Hidden layers transform those features into increasingly abstract representations. The output layer produces the final prediction (a class, a number, a sequence).

Weights, bias, parameters & hyperparameters

DefinitionWeights scale each input's importance; bias shifts the activation threshold. Together, weights and biases are the model's parameters — learned automatically during training. Hyperparameters (learning rate, number of layers, batch size…) are settings a human chooses before training starts.

Forward propagation

DefinitionForward propagation is the process of pushing input data through the network layer by layer — each layer computing activation(W·x + b) — to produce a final output/prediction.
import numpy as np

def sigmoid(z): return 1 / (1 + np.exp(-z))

# a 2-input, 3-hidden-neuron, 1-output network
X  = np.array([0.5, 0.8])
W1 = np.random.randn(3, 2) * 0.1;  b1 = np.zeros(3)
W2 = np.random.randn(1, 3) * 0.1;  b2 = np.zeros(1)

h  = sigmoid(W1 @ X + b1)     # hidden layer activations
y_hat = sigmoid(W2 @ h + b2)  # output / prediction
print("prediction:", y_hat)

Loss function (introduced here, detailed in Unit 5)

DefinitionA loss function measures how wrong a prediction is compared to the true label — a single number the whole training process tries to minimise.

Backpropagation & gradient descent (introduced here, detailed in Unit 6)

DefinitionBackpropagation uses the chain rule to compute how much each weight contributed to the error, walking backward from the output layer to the input layer. Gradient descent then updates every weight a small step in the direction that reduces the loss.
ExampleIf increasing a particular weight by a tiny amount would increase the loss, backprop reports a positive gradient for that weight, and gradient descent decreases it slightly.
UNIT 04

Activation Functions

Without a non-linear activation, stacking any number of layers collapses mathematically into one linear layer. Activation functions are what give deep networks their expressive power.

Why non-linearity matters

DefinitionAn activation function is applied to a neuron's weighted sum to introduce non-linearity, letting the network approximate curved, complex decision boundaries instead of only straight lines/planes.

Sigmoid, Tanh, ReLU family, Softmax — definitions and code

FunctionFormulaRangeTypical use
Sigmoid1 / (1 + e-x)(0, 1)Binary output probability
Tanh(ex-e-x) / (ex+e-x)(-1, 1)Zero-centred hidden layers, RNNs
ReLUmax(0, x)[0, ∞)Default for hidden layers in CNNs/MLPs
Leaky ReLU / PReLUx if x>0 else αx(-∞, ∞)Fixes ReLU's "dead neuron" problem
ELU / SELUsmooth negative branch(-α, ∞)Faster, self-normalising training
GELU / Swish / Mishsmooth, self-gated(-≈0.3, ∞)Transformers (BERT, GPT)
Softmaxex_i / Σex_j(0,1), sums to 1Multi-class output layer
import numpy as np

sigmoid    = lambda x: 1/(1+np.exp(-x))
tanh       = lambda x: np.tanh(x)
relu       = lambda x: np.maximum(0, x)
leaky_relu = lambda x, a=0.01: np.where(x>=0, x, a*x)

def softmax(x):
    e = np.exp(x - np.max(x))   # subtract max for numerical stability
    return e / e.sum()

logits = np.array([2.0, 1.0, 0.1])
print(softmax(logits))   # → [0.659, 0.242, 0.099] — probabilities summing to 1

Choosing an activation function

Rule of thumb — ReLU (or a variant) for hidden layers in CNNs/MLPs; GELU/Swish for Transformers; Sigmoid for binary output; Softmax for multi-class output; Tanh inside classic RNN/LSTM gates.
UNIT 05

Loss Functions

The loss function is the single number the entire network is trained to shrink. Picking the wrong one silently sabotages training.

Regression losses — MSE & MAE

DefinitionMean Squared Error averages the squared difference between prediction and target (punishes big errors heavily). Mean Absolute Error averages the absolute difference (more robust to outliers).
y_true = np.array([3.0, 5.0, 2.5])
y_pred = np.array([2.5, 5.5, 2.0])

mse = np.mean((y_true - y_pred)**2)
mae = np.mean(np.abs(y_true - y_pred))

Classification losses — Binary / Categorical / Sparse Categorical Cross-Entropy

DefinitionCross-entropy measures the distance between the true label distribution and the predicted probability distribution — the lower the loss, the more confident and correct the prediction. Binary cross-entropy is for two classes; Categorical for one-hot-encoded multi-class labels; Sparse Categorical is the same but accepts integer class labels directly (no one-hot needed).
def binary_cross_entropy(y_true, y_pred, eps=1e-9):
    y_pred = np.clip(y_pred, eps, 1-eps)
    return -np.mean(y_true*np.log(y_pred) + (1-y_true)*np.log(1-y_pred))

y_true = np.array([1, 0, 1])
y_pred = np.array([0.9, 0.2, 0.6])
print(binary_cross_entropy(y_true, y_pred))

Specialised losses — Hinge, Focal, Contrastive, Triplet, KL divergence

LossDefinitionTypical use
Hinge lossPenalises predictions inside the decision marginSVMs, max-margin classifiers
Focal lossDown-weights easy examples, focuses on hard onesObject detection with class imbalance (RetinaNet)
Contrastive lossPulls similar pairs together, pushes dissimilar pairs apartSiamese networks, face verification
Triplet lossAnchor closer to positive than to negative by a marginFace recognition embeddings
KL divergenceMeasures how one probability distribution diverges from a reference oneVAEs, knowledge distillation
UNIT 06

Training Deep Neural Networks — Backprop, Gradient Descent & Optimizers

This is the training engine: how error flows backward, how weights move, and the family of optimizers that make that movement fast and stable.

Backpropagation in detail

DefinitionBackpropagation computes the gradient of the loss with respect to every weight in the network by applying the chain rule from the output layer backward to the input layer, reusing intermediate derivatives (the "computational graph") so nothing is recomputed twice. Frameworks like PyTorch do this automatically — automatic differentiation.
import torch

x = torch.tensor([2.0], requires_grad=True)
w = torch.tensor([3.0], requires_grad=True)
b = torch.tensor([1.0], requires_grad=True)

y_hat = w * x + b            # forward pass
loss  = (y_hat - 10.0)**2   # squared error against target 10

loss.backward()              # backprop — computes gradients automatically
print(w.grad, b.grad)     # dLoss/dw, dLoss/db

Gradient descent variants

DefinitionBatch GD computes the gradient over the entire dataset before each update (accurate, slow). Stochastic GD (SGD) updates after every single example (fast, noisy). Mini-batch GD — the practical default — updates after small batches (e.g. 32–256 examples), balancing speed and stability.
DefinitionThe learning rate controls step size. Too high → the loss diverges or oscillates; too low → training crawls or gets stuck in a local minimum/saddle point instead of reaching the global minimum.
DefinitionVanishing gradients occur when gradients shrink to near-zero through many layers (common with Sigmoid/Tanh in deep nets), so early layers stop learning. Exploding gradients are the opposite — gradients grow uncontrollably, destabilising training. Fixes include ReLU-family activations, normalization, gradient clipping, and residual connections.

Optimization algorithms

OptimizerCore idea
SGDPlain step in the negative gradient direction
MomentumAdds a "velocity" term so updates keep moving in a consistent direction, damping oscillation
Nesterov MomentumLooks ahead to where momentum would take you before computing the gradient
AdaGradGives infrequent features bigger updates by dividing by accumulated squared gradients
RMSPropFixes AdaGrad's shrinking learning rate using a moving average of squared gradients
AdamCombines Momentum + RMSProp — the default optimizer for most deep learning today
AdamWAdam with weight decay decoupled from the gradient update — standard for Transformers
import torch, torch.nn as nn

model = nn.Linear(10, 1)
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=50)

for epoch in range(50):
    optimizer.zero_grad()
    loss = ((model(torch.randn(10)) - 1.0)**2)
    loss.backward()
    optimizer.step()      # apply the AdamW update rule
    scheduler.step()      # cosine-decay the learning rate
Learning-rate scheduling — warm-up starts the LR small and ramps up (stabilises early Transformer training); cosine decay smoothly reduces LR over training; ReduceLROnPlateau cuts the LR only when validation loss stops improving.

Weight initialization

DefinitionStarting weights at exactly zero makes every neuron learn the same thing (symmetry problem), so weights are initialised randomly and scaled to keep signal variance stable across layers. Xavier/Glorot suits Sigmoid/Tanh; He initialization suits ReLU; LeCun suits SELU; Orthogonal helps very deep/recurrent nets.
layer = nn.Linear(256, 128)
nn.init.kaiming_normal_(layer.weight, nonlinearity='relu')  # He init
UNIT 07

Regularization & Normalization

A network that memorises the training set instead of learning general patterns is overfit. Regularization and normalization are the toolbox for keeping a network general.

Overfitting, underfitting & the bias-variance trade-off

DefinitionOverfitting is when a model fits training data (including its noise) so closely that it performs poorly on new data — high variance. Underfitting is when a model is too simple to capture the pattern at all — high bias. The bias-variance trade-off is the balancing act between the two.
ExampleA student who memorises last year's exam answers word-for-word (overfitting) fails when this year's questions are phrased differently; a student who barely studied (underfitting) fails both.

L1 / L2 regularization & weight decay

DefinitionL2 regularization adds the sum of squared weights to the loss, discouraging any single weight from growing too large. L1 regularization adds the sum of absolute weights, which pushes many weights to exactly zero (sparse models, built-in feature selection). Weight decay is the practical implementation of L2 applied directly during the optimizer's update step.
l2_penalty = 0.001 * sum((w**2).sum() for w in model.parameters())
total_loss = data_loss + l2_penalty

Dropout & DropConnect

DefinitionDropout randomly switches off a fraction of neurons during each training step, forcing the network to not rely on any single neuron — an implicit ensemble of sub-networks. DropConnect does the same but drops individual weights instead of whole neurons.
model = nn.Sequential(
    nn.Linear(784, 256), nn.ReLU(), nn.Dropout(0.3),  # drop 30% of activations
    nn.Linear(256, 10)
)

Early stopping, data augmentation & noise injection

DefinitionEarly stopping halts training as soon as validation loss stops improving, before the model starts memorising. Data augmentation creates realistic variations of training samples (flips, crops, noise) to expand the effective dataset. Noise injection adds small random noise to inputs/weights during training so the model doesn't over-rely on exact values.

Normalization — Batch / Layer / Instance / Group / RMSNorm

DefinitionNormalization rescales activations to have stable mean/variance at every layer, which lets you train deeper networks with higher learning rates and fewer vanishing/exploding gradient problems. Batch Norm normalises across the batch dimension (CNNs); Layer Norm normalises across features for each sample independently (Transformers, RNNs); Instance Norm per-sample-per-channel (style transfer); Group Norm normalises groups of channels (small-batch vision models); RMSNorm is a simplified, faster Layer Norm used in modern LLMs (e.g. LLaMA).
nn.Sequential(
    nn.Conv2d(3, 64, 3, padding=1),
    nn.BatchNorm2d(64),   # normalize activations across the batch
    nn.ReLU()
)
UNIT 08

Convolutional Neural Networks (CNN)

CNNs exploit the fact that nearby pixels are related — instead of connecting every pixel to every neuron, a small filter slides across the image, sharing weights and drastically cutting parameters.

Why CNNs, and the convolution operation

DefinitionA convolution slides a small learnable grid of numbers (the kernel/filter) across the input image, computing a weighted sum at each position to produce a feature map. Stride is how many pixels the kernel moves each step; padding adds border pixels so the output size is controlled ("valid" = no padding, "same" = output same size as input); the receptive field is the region of the original image a given output pixel "sees".
ExampleA 3×3 edge-detecting kernel produces a bright output wherever pixel intensity changes sharply — an edge — and near-zero output over flat, uniform regions.
import torch, torch.nn as nn

conv = nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, stride=1, padding=1)
image = torch.randn(1, 3, 64, 64)   # batch=1, RGB, 64x64
feature_map = conv(image)
print(feature_map.shape)         # torch.Size([1, 16, 64, 64])

Pooling — max, average, global

DefinitionPooling downsamples feature maps to reduce size and add translation-invariance. Max pooling keeps the strongest activation in each window (retains sharp features); average pooling takes the mean (smoother); global average/max pooling collapses an entire feature map to a single number per channel, often replacing fully-connected layers before the output.
pool = nn.MaxPool2d(kernel_size=2, stride=2)   # halves height & width
gap  = nn.AdaptiveAvgPool2d(1)               # global average pooling

Full CNN architecture & a minimal working classifier

DefinitionA typical CNN stacks: Input → [Conv → Activation → Pool] × N → Flatten → Fully-connected → Output.
class SimpleCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),  # 28x28 → 14x14
            nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2), # 14x14 → 7x7
        )
        self.classifier = nn.Linear(64*7*7, num_classes)

    def forward(self, x):
        x = self.features(x)
        x = x.view(x.size(0), -1)     # flatten
        return self.classifier(x)

model = SimpleCNN()                          # e.g. MNIST digit classifier
dummy = torch.randn(8, 1, 28, 28)          # batch of 8 grayscale 28x28 digits
print(model(dummy).shape)               # torch.Size([8, 10])

UNIT 09

Recurrent Neural Networks — RNN, LSTM, GRU

CNNs assume inputs are spatially related; RNNs assume inputs are sequentially related — text, speech, time-series — where order and memory of the past matter.

Basic RNN & the hidden state

DefinitionAn RNN processes a sequence one element at a time, maintaining a hidden state — a running summary of everything seen so far — that is updated at every step: h_t = tanh(W_x·x_t + W_h·h_(t-1) + b). "Unrolling" means drawing the same RNN cell repeated once per time-step to visualise/backprop through it.
ExampleReading the sentence "The clouds are in the ___", the hidden state after "clouds" and "are" already encodes enough context to bias the network toward predicting "sky".
rnn = nn.RNN(input_size=10, hidden_size=20, batch_first=True)
x = torch.randn(4, 15, 10)     # batch=4, sequence length=15, features=10
output, h_n = rnn(x)          # output: hidden state at every step; h_n: final hidden state

Backpropagation Through Time (BPTT) & RNN's core problem

DefinitionBPTT unrolls the RNN across all time steps and applies backprop across that unrolled chain. Because the same weight is multiplied repeatedly (once per time step), gradients either shrink toward zero (vanishing gradient — long-term dependencies get "forgotten") or blow up (exploding gradient) over long sequences — this is the plain RNN's fundamental weakness, motivating LSTM/GRU.

LSTM — Long Short-Term Memory

DefinitionAn LSTM adds a separate cell state (a long-term memory conveyor belt) alongside the hidden state, controlled by three gates: the forget gate decides what to discard from the cell state, the input gate decides what new information to add, and the output gate decides what to expose as the hidden state. This gating lets gradients flow over long sequences without vanishing.
lstm = nn.LSTM(input_size=10, hidden_size=20, num_layers=1,
               batch_first=True, bidirectional=True)   # reads sequence both directions
x = torch.randn(4, 15, 10)
output, (h_n, c_n) = lstm(x)   # c_n = final cell state (the long-term memory)

GRU — Gated Recurrent Unit

DefinitionA GRU simplifies the LSTM into just two gates — the update gate (how much of the past to keep) and the reset gate (how much of the past to forget when computing a new candidate state) — with no separate cell state. It trains faster with fewer parameters and often matches LSTM accuracy.
LSTMGRU
Gates3 (forget, input, output)2 (update, reset)
MemorySeparate cell state + hidden stateHidden state only
SpeedSlower, more parametersFaster, fewer parameters

Sequence-to-sequence, encoder-decoder & attention (bridge to Unit 11)

DefinitionA sequence-to-sequence (seq2seq) model uses an encoder RNN to compress an entire input sequence into a context vector, and a decoder RNN to generate the output sequence from it — the architecture behind early machine translation. Plain seq2seq struggles with long inputs because everything is squeezed through one fixed-size vector; the attention mechanism (Unit 11) fixes this by letting the decoder look back at all encoder states.

RNN applications

DefinitionLanguage modelling, machine translation, speech recognition, sentiment analysis, time-series forecasting (stock prices, weather), and text generation.
UNIT 10

Autoencoders & Representation Learning

Autoencoders learn to compress data and reconstruct it, and in doing so are forced to discover the most important underlying structure in the data.

Autoencoder fundamentals

DefinitionAn autoencoder is a network trained to reproduce its own input. The encoder compresses the input into a small latent representation (bottleneck); the decoder reconstructs the original input from that latent code. Training minimises the reconstruction loss (e.g. MSE between input and output) — no labels needed, so it's self-supervised.
class Autoencoder(nn.Module):
    def __init__(self, in_dim=784, latent_dim=32):
        super().__init__()
        self.encoder = nn.Sequential(nn.Linear(in_dim, 128), nn.ReLU(), nn.Linear(128, latent_dim))
        self.decoder = nn.Sequential(nn.Linear(latent_dim, 128), nn.ReLU(), nn.Linear(128, in_dim), nn.Sigmoid())

    def forward(self, x):
        z = self.encoder(x)          # compress → latent code
        x_hat = self.decoder(z)      # reconstruct
        return x_hat, z

model = Autoencoder()
x = torch.rand(16, 784)                # 16 flattened 28x28 images
x_hat, z = model(x)
loss = nn.functional.mse_loss(x_hat, x)   # reconstruction loss

Variational Autoencoders (VAE)

DefinitionInstead of encoding an input to one fixed point, a VAE encodes it as a probability distribution (mean + variance) in latent space. The reparameterization trick lets you sample from that distribution while still allowing gradients to flow through. Training minimises reconstruction loss + KL divergence (keeping the latent distribution close to a standard normal) — together called the ELBO (Evidence Lower Bound). Because the latent space is smooth and continuous, you can sample new points from it to generate brand-new data.
ExampleA VAE trained on handwritten digits can generate a plausible new "7" by sampling a random point near the region of latent space the "7"s occupied during training.

Applications

DefinitionDimensionality reduction, feature extraction, data compression, denoising, anomaly detection (high reconstruction error flags anomalies), and image reconstruction/generation.
UNIT 11

Transformers & Attention

The architecture behind BERT, GPT, and virtually every modern LLM — it replaced recurrence entirely with a mechanism that looks at every position in a sequence simultaneously.

The attention mechanism — Query, Key, Value

DefinitionAttention lets a model decide, for each element in a sequence, how much to "attend to" every other element. Each token is projected into three vectors: Query (what am I looking for), Key (what do I contain), Value (what information do I offer). The attention score between two tokens is the dot product of one's Query with the other's Key; scaled and passed through Softmax to get attention weights, which weight-average the Values into a context vector.
ExampleIn "The animal didn't cross the street because it was too tired", attention lets the model learn that "it" should attend strongly to "animal", not "street" — resolving the reference correctly.
import torch, torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V):
    d_k = Q.size(-1)
    scores = Q @ K.transpose(-2, -1) / (d_k ** 0.5)  # QK^T / sqrt(d_k)
    weights = F.softmax(scores, dim=-1)                     # attention weights
    return weights @ V, weights                          # context vector

seq_len, d_model = 5, 16
Q = K = V = torch.randn(1, seq_len, d_model)
context, attn_weights = scaled_dot_product_attention(Q, K, V)
print(context.shape)   # torch.Size([1, 5, 16])

Self-attention & multi-head attention

DefinitionSelf-attention applies attention within a single sequence — every token attends to every other token in the same sentence. Multi-head attention runs several self-attention operations in parallel with different learned projections, letting the model capture different types of relationships (e.g. one head tracks syntax, another tracks coreference) simultaneously.
mha = nn.MultiheadAttention(embed_dim=64, num_heads=8, batch_first=True)
x = torch.randn(2, 10, 64)         # batch=2, seq_len=10, embed_dim=64
out, attn_weights = mha(x, x, x)  # self-attention: Q=K=V=x

Full Transformer architecture

DefinitionA Transformer block = Multi-head self-attention → residual connection + Layer Norm → position-wise Feed-Forward network → residual connection + Layer Norm. Since attention has no sense of order, positional encoding (fixed sine/cosine waves or learned embeddings) is added to token embeddings so the model knows sequence order. The encoder processes the input sequence; the decoder generates output tokens one at a time, using masked attention (a token can only attend to earlier tokens, not future ones) plus encoder-decoder attention to look back at the encoder's output.

DefinitionTranslation, text classification, question answering, text generation, summarisation, code generation, and (via Vision Transformers) multimodal AI.
UNIT 12

Generative Deep Learning — GANs & Diffusion Models

Discriminative models answer "what is this?"; generative models answer "can you make me a new one of these?" by learning the underlying data distribution.

Discriminative vs generative models

DefinitionA discriminative model learns the decision boundary P(label | data) — e.g. "is this a cat?". A generative model learns the full data distribution P(data) so it can sample entirely new, realistic examples.

GANs — Generative Adversarial Networks

DefinitionA GAN pits two networks against each other: the generator tries to create fake data realistic enough to fool the discriminator, while the discriminator tries to correctly tell real from fake. This adversarial training pushes the generator toward producing increasingly realistic samples. Known failure modes: mode collapse (generator produces very limited variety) and general training instability (the two networks can fail to converge).
# minimal GAN training step (PyTorch-style pseudocode)
real_images = next(data_loader)
noise = torch.randn(batch_size, 100)
fake_images = generator(noise)

# 1) train discriminator: real → 1, fake → 0
d_loss = bce(discriminator(real_images), torch.ones(batch_size, 1)) \
       + bce(discriminator(fake_images.detach()), torch.zeros(batch_size, 1))
d_loss.backward(); d_optimizer.step()

# 2) train generator: wants discriminator to say fake → 1 ("real")
g_loss = bce(discriminator(fake_images), torch.ones(batch_size, 1))
g_loss.backward(); g_optimizer.step()

Diffusion models

DefinitionDiffusion models learn to generate data by reversing a gradual noising process. In forward diffusion, Gaussian noise is added to an image over many steps until it becomes pure noise. A network is trained to perform reverse diffusion — predicting and removing a little noise at each step (noise prediction / denoising) — so that starting from pure random noise and iteratively denoising ("sampling") produces a brand-new realistic image. DDPM and the faster DDIM are the classic sampling schedules; latent diffusion (Stable Diffusion) runs this process in a compressed latent space instead of raw pixels for speed.
ExampleText-to-image tools like Stable Diffusion start from random noise and, guided by a text embedding at every denoising step, gradually "sculpt" that noise into an image matching the prompt.

Generative applications

DefinitionImage generation and editing, text generation, audio/music generation, video generation, and synthetic data generation for training other models.
UNIT 13

Deep Learning for Natural Language Processing

Turning messy human text into numbers a network can learn from, up through today's large language models.

Text preprocessing

DefinitionTokenization splits text into units (words, subwords, or characters). Sentence segmentation splits a document into sentences. Stop words (the, is, at…) are often removed for classical NLP. Stemming crudely chops word endings ("running" → "run"); lemmatization does the same more correctly using grammar ("better" → "good").
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")
tokens = tokenizer("Deep learning models tokenize text.")
print(tokens["input_ids"])  # integer IDs the model actually consumes

Text representation — from one-hot to embeddings

DefinitionOne-hot encoding represents each word as a huge sparse vector with a single 1. Bag of Words counts word occurrences, ignoring order. TF-IDF weights words by how distinctive they are to a document versus the whole corpus. Word embeddings (Word2Vec, GloVe, FastText) instead learn dense, low-dimensional vectors where semantically similar words end up close together — e.g. vector("king") − vector("man") + vector("woman") ≈ vector("queen").

Large Language Models (LLMs)

DefinitionAn LLM is a Transformer-decoder trained on massive text corpora in two stages: pretraining (predict the next token over huge unlabelled text) and fine-tuning/instruction tuning (adapt it to follow instructions and be helpful/safe). Key runtime concepts: the context window (how many tokens it can consider at once), temperature (randomness of sampling — low = deterministic, high = creative), top-k/top-p (restrict sampling to the most likely k tokens, or the smallest set whose probabilities sum past p). Prompt engineering is the practice of crafting inputs to reliably get the output you want.

Retrieval-Augmented Generation (RAG)

DefinitionRAG grounds an LLM's answers in an external knowledge source: relevant documents are converted to embeddings and stored in a vector database; at query time, semantic search retrieves the most relevant chunks, which are inserted into the prompt so the model answers using up-to-date, verifiable facts instead of only its frozen training data.
# conceptual RAG pipeline
query_vec = embed_model.encode(user_question)
top_chunks = vector_db.similarity_search(query_vec, k=4)
prompt = build_prompt(context=top_chunks, question=user_question)
answer = llm.generate(prompt)
UNIT 14

Deep Learning for Computer Vision

Beyond plain classification: finding, outlining, and understanding objects within an image.

Image classification types & transfer learning

DefinitionBinary classification picks between 2 classes, multiclass between many mutually-exclusive classes, multilabel allows several labels per image at once (e.g. a photo tagged both "beach" and "sunset"). Transfer learning reuses a CNN pretrained on a huge dataset (e.g. ImageNet) as a feature extractor for a new, smaller dataset — detailed fully in Unit 15.

Object detection

DefinitionObject detection locates objects with a bounding box and classifies each one. IoU (Intersection over Union) measures overlap between predicted and true boxes; Non-Maximum Suppression removes duplicate overlapping boxes for the same object, keeping only the highest-confidence one; mAP (mean Average Precision) is the standard accuracy metric across all classes and IoU thresholds.
FamilyIdea
R-CNN → Fast R-CNN → Faster R-CNNTwo-stage: propose regions, then classify each — accurate but slower
SSD, YOLOOne-stage: predict boxes + classes in a single pass — real-time speed

def iou(boxA, boxB):
    xA = max(boxA[0], boxB[0]); yA = max(boxA[1], boxB[1])
    xB = min(boxA[2], boxB[2]); yB = min(boxA[3], boxB[3])
    inter = max(0, xB-xA) * max(0, yB-yA)
    areaA = (boxA[2]-boxA[0])*(boxA[3]-boxA[1])
    areaB = (boxB[2]-boxB[0])*(boxB[3]-boxB[1])
    return inter / (areaA + areaB - inter + 1e-9)

Image segmentation

DefinitionSemantic segmentation labels every pixel with a class (all "cat" pixels marked the same, no individual identity). Instance segmentation additionally separates individual object instances (cat #1 vs cat #2). Panoptic segmentation combines both — every pixel gets a class, and object instances are distinguished. U-Net (encoder-decoder with skip connections, popular in medical imaging), Mask R-CNN (adds a mask branch to Faster R-CNN), and DeepLab (atrous/dilated convolutions) are the standard architectures.

Advanced vision — ViT & CLIP

DefinitionA Vision Transformer (ViT) chops an image into fixed-size patches, treats each patch like a "word" token, and processes them with a standard Transformer encoder — no convolutions needed. CLIP jointly trains an image encoder and a text encoder to place matching image/caption pairs close together in a shared embedding space, enabling zero-shot image classification purely from text labels.
UNIT 15

Transfer Learning & Fine-Tuning

Training a large model from scratch is expensive; transfer learning lets you stand on the shoulders of a model someone else already trained on millions of examples.

Transfer learning & fine-tuning

DefinitionTransfer learning reuses a model pretrained on a large source domain (e.g. ImageNet) for a new, related target domain with less data, typically by using its early layers as a fixed feature extractor. Fine-tuning goes further by continuing to train some or all of the pretrained weights on the new task: freezing layers keeps their weights fixed, unfreezing lets them update; full fine-tuning retrains the entire model (expensive), partial fine-tuning updates only the last few layers (cheap, works well with limited data). The learning rate is usually set much lower than for training from scratch, to avoid destroying the pretrained knowledge.
import torchvision.models as models

model = models.resnet18(weights="IMAGENET1K_V1")   # pretrained on ImageNet
for param in model.parameters():
    param.requires_grad = False                  # freeze the backbone

model.fc = nn.Linear(model.fc.in_features, 2)      # new head: 2 classes (e.g. cat vs dog)
# only model.fc's weights will receive gradient updates

Parameter-Efficient Fine-Tuning (PEFT) — LoRA & QLoRA

DefinitionPEFT adapts a huge pretrained model (e.g. an LLM with billions of parameters) by training only a small number of new parameters instead of the whole model. LoRA (Low-Rank Adaptation) freezes the original weight matrices and injects small trainable low-rank matrices alongside them, cutting trainable parameters by 1000×+ while matching full fine-tuning quality. QLoRA combines LoRA with 4-bit quantization of the frozen base model, so you can fine-tune a huge LLM on a single consumer GPU. Adapters insert small trainable bottleneck layers between frozen Transformer blocks; prefix/prompt tuning learns a small set of virtual tokens prepended to the input instead of touching model weights at all.
from peft import LoraConfig, get_peft_model

config = LoraConfig(r=8, lora_alpha=16, target_modules=["q_proj", "v_proj"], lora_dropout=0.05)
model = get_peft_model(base_llm, config)
model.print_trainable_parameters()   # e.g. "trainable: 0.06% of all parameters"

Model adaptation — domain, task, few-shot & zero-shot

DefinitionDomain adaptation adjusts a model trained on one data distribution (e.g. daytime photos) to perform on a related but different one (e.g. night photos). Task adaptation repurposes a model for a different task entirely. Few-shot learning asks a model to generalise from only a handful of labelled examples; zero-shot learning asks it to handle a task or class it never saw an example of, relying purely on prior knowledge (e.g. text descriptions in CLIP).

UNIT 18

Model Evaluation

A model is not "done" once it trains — it must be measured with metrics that match the task and reveal where it actually fails.

Classification metrics

DefinitionA confusion matrix tallies True Positives, False Positives, True Negatives, False Negatives. Accuracy = correct / total (misleading on imbalanced data). Precision = TP/(TP+FP) — of everything predicted positive, how much was right. Recall (Sensitivity) = TP/(TP+FN) — of everything actually positive, how much was caught. Specificity = TN/(TN+FP). F1-score is the harmonic mean of precision and recall. The ROC curve plots true-positive rate vs false-positive rate across thresholds, and AUC summarises it as one number (1.0 = perfect, 0.5 = random).
from sklearn.metrics import classification_report, confusion_matrix, roc_auc_score

y_true = [1,0,1,1,0,1]
y_pred = [1,0,0,1,0,1]
print(confusion_matrix(y_true, y_pred))
print(classification_report(y_true, y_pred))  # precision, recall, F1 per class

UNIT 19

Hyperparameter Optimization

Hyperparameters aren't learned by gradient descent — they have to be searched for.

Important hyperparameters

DefinitionLearning rate, batch size, number of epochs, number of layers/neurons, dropout rate, choice of optimizer, weight decay, and activation function are the settings that most influence training outcome and usually need tuning per-dataset.

Search strategies

DefinitionGrid search exhaustively tries every combination on a fixed grid (thorough but expensive). Random search samples random combinations — often finds a good setting faster because it doesn't waste trials on unimportant dimensions. Bayesian optimization builds a probabilistic model of "hyperparameters → performance" and picks the next trial expected to improve most. Hyperband/population-based training allocate more compute to promising trials early and kill unpromising ones, saving time.

DefinitionExperiment logging records every run's hyperparameters, metrics, and artifacts so results are reproducible and comparable. UNIT 20

Advanced Deep Learning

How modern models learn useful representations without needing millions of hand-labelled examples.

Self-supervised & contrastive learning

DefinitionSelf-supervised learning creates its own labels from the structure of unlabelled data using a pretext task — e.g. predicting a masked word (BERT), or colourising a grayscale image. Contrastive learning trains a model so that augmented views of the same image (a positive pair) end up close together in embedding space, while different images (negative pairs) are pushed apart — the basis of SimCLR, MoCo, and BYOL. Masked modelling (masking patches/tokens and predicting them) is the same idea applied to text (BERT) and images (masked autoencoders).

Few-shot & zero-shot learning

DefinitionOne-shot/few-shot learning classifies new categories from only one or a handful of examples, often via meta-learning ("learning to learn" across many small tasks) or prototypical networks (classify by nearest class-average embedding). Zero-shot learning classifies categories never seen during training at all, typically by relating a new class's textual description to the model's learned semantic space (CLIP-style).

Multimodal deep learning

DefinitionMultimodal models process and relate more than one data type at once — text+image, text+audio, image+audio — usually by encoding each modality separately and fusing them in a shared embedding space, enabling tasks like image captioning, visual question answering, and multimodal chat assistants.
UNIT 21

Deep Reinforcement Learning

Instead of learning from labelled examples, an RL agent learns from trial and error, guided only by a reward signal.

Reinforcement learning basics

DefinitionAn agent interacts with an environment: at each state, it takes an action, receives a reward, and transitions to a new state. A policy maps states to actions; a value function estimates expected future reward from a state. The goal is to learn a policy that maximises cumulative reward over time.
ExampleIn a game of chess, the state is the board position, actions are legal moves, and reward is +1 for winning, -1 for losing, 0 otherwise — the agent must learn which moves lead to reward many turns later.

Deep Q-Learning (DQN)

DefinitionQ-learning learns a function Q(state, action) estimating expected future reward for taking that action in that state. DQN approximates Q with a neural network so it scales to huge state spaces (like raw pixels). Experience replay stores past transitions in a buffer and samples random mini-batches from it to train on, breaking harmful correlation between consecutive steps. A separate, slowly-updated target network stabilises training by keeping the Q-value targets from shifting every step.
# simplified DQN update
state, action, reward, next_state, done = replay_buffer.sample()

q_values      = q_network(state)
next_q_values = target_network(next_state).max(dim=1).values
target        = reward + (1 - done) * gamma * next_q_values   # Bellman equation

loss = mse_loss(q_values.gather(1, action), target)
loss.backward(); optimizer.step()

Interpretability, Security & Model Optimization

Making deep networks trustworthy (explainable, robust) and deployable on constrained hardware.

LIME explains one prediction locally by fitting a simple interpretable model around it. Saliency maps/Grad-CAM highlight which pixels of an image most influenced a CNN's decision. Adversarial machine learning & defenses

DefinitionAn adversarial example is an input with tiny, often human-imperceptible perturbations crafted to fool a model. FGSM (Fast Gradient Sign Method) creates one by nudging the input in the direction that most increases the loss; PGD does this iteratively for a stronger attack. Poisoning attacks corrupt training data itself; backdoor attacks plant a hidden trigger pattern; model/membership-inference attacks try to steal a model or infer whether specific data was in its training set. Defenses include adversarial training (train on adversarial examples too), input preprocessing, robust optimization, and differential privacy (mathematically bounding what any single training example can reveal).
# FGSM attack — one gradient step toward increasing the loss
x.requires_grad = True
loss = loss_fn(model(x), true_label)
loss.backward()
x_adv = x + epsilon * x.grad.sign()   # small perturbation in the worst direction

Model compression & efficient AI

DefinitionPruning removes redundant weights/neurons with little accuracy loss. Quantization stores weights in lower precision (FP16, BF16, INT8, even INT4) to shrink memory and speed up inference. Knowledge distillation trains a small "student" model to mimic a large "teacher" model's outputs, transferring most of its accuracy into a fraction of the size. Together with efficient architectures, these enable Edge AI, mobile AI, and TinyML — running models on phones, microcontrollers, and other low-power devices.

Model formats & MLOps

DefinitionONNX, TensorFlow's SavedModel, PyTorch's TorchScript, and NVIDIA's TensorRT are portable/optimised formats for exporting a trained model to run efficiently outside its original framework. MLOps extends DevOps practice to ML: data and model versioning, a model registry, CI/CD pipelines that test and deploy new model versions automatically, and monitoring for data drift (input distribution changes) and concept drift (the relationship between input and target changes), which trigger retraining pipelines.

Cloud & distributed training

DefinitionLarge models are trained across many GPUs/machines using data parallelism (same model, different data shards, gradients averaged — Distributed Data Parallel/DDP), model parallelism (different parts of one huge model on different devices), or pipeline parallelism (different layers on different devices, processed in a pipeline). Cloud GPU platforms (AWS, Google Cloud, Microsoft Azure) rent this hardware on demand for both single-node and multi-node training.
UNIT 24

Advanced Generative AI, AI Agents & Research-Level Deep Learning

The frontier: aligning LLMs to be helpful, wiring them to tools and memory, and the open research directions pushing the field forward.

LLM alignment — RLHF & DPO

DefinitionAfter pretraining and instruction tuning, LLMs are aligned to human preferences. RLHF (Reinforcement Learning from Human Feedback) trains a reward model on human preference comparisons, then uses RL (typically PPO) to optimise the LLM against that reward. DPO (Direct Preference Optimization) achieves a similar alignment effect directly from preference data, without needing a separate reward model or RL loop — simpler and more stable to train.

RAG pipeline, in detail

DefinitionA production RAG pipeline: document ingestion → chunking (splitting long documents into retrievable pieces) → embedding generation for each chunk → storage in a vector database → at query time, similarity search retrieves candidate chunks → optional reranking (a second, more precise model reorders candidates) → context construction (assembling the final prompt) → generation by the LLM. RAG evaluation checks both retrieval quality (did we fetch the right chunks?) and generation quality (did the model use them correctly?).

AI agents

DefinitionAn AI agent extends an LLM with: tools (external functions it can call — search, calculators, APIs) via function calling; planning (breaking a goal into steps); memory (retaining information across steps or sessions); and reflection (critiquing and revising its own output). Multi-agent systems coordinate several specialised agents on one task; the overall loop of plan → act → observe → reflect is called an agentic workflow.
