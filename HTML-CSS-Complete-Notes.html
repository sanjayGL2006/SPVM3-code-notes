Part One

HTML — HyperText Markup Language

1. What is HTML?

HTML (HyperText Markup Language) is not a programming language — it is a markup language. It describes the structure and meaning of content in a web page using elements, written as tags. A browser reads an HTML file and renders it as a visible page. HTML gives content its skeleton; CSS gives it appearance; JavaScript gives it behaviour.

  • HyperText — text containing links to other text (hyperlinks).
  • Markup — tags that "mark up" plain text to describe what it is (a heading, a paragraph, a link…).
  • Current version: HTML5, which added semantic tags, audio/video, canvas, and form improvements.

3. Elements, tags, and attributes

An element is a piece of content plus its markup. A tag is the markup itself. Most elements have an opening tag and a closing tag, wrapping content: <p>content</p>. Some elements are void (self-closing, no content and no closing tag): <br>, <img>, <input>, <hr>, <meta>, <link>.

Attributes live inside the opening tag and give extra information: <a href="https://example.com" target="_blank">link</a>. Format is always name="value".

Global attributePurpose
idUnique identifier for one element (used by CSS #id and JS).
classReusable label shared by many elements (used by CSS .class).
styleInline CSS applied only to that element.
titleTooltip text shown on hover.
data-*Custom data attribute for storing extra info, e.g. data-user-id="42".
hiddenHides the element from the page.
HTML tags are case-insensitive, but the universal convention is lowercase. Attribute values should always be quoted.

HTML comments

Comments are ignored by the browser and used to leave notes in the code:

<!-- this is a comment and will not be shown on the page -->

Part Two

CSS — Cascading Style Sheets

11. What is CSS & basic syntax

CSS describes how HTML elements should look — color, spacing, layout, fonts, animation. A CSS rule has a selector (what to style) and a declaration block of property: value; pairs.

selector {
  property: value;
  property: value;
}

/* example */
p {
  color: navy;
  font-size: 16px;
}

Quick Reference

Cheat sheet

How to write and run HTML/CSS on your own computer

  1. Open any text editor (VS Code is the standard free choice).
  2. Create a file named index.html.
  3. Write your HTML, and either write CSS inside a <style> tag or link a separate styles.css file with <link rel="stylesheet" href="styles.css"> in the <head>.
  4. Save the file, then double-click it (or right-click → Open with → your browser) to view it. No installation, compiler, or server is required for static pages.
  5. In VS Code, the "Live Server" extension auto-refreshes the browser every time you save — the fastest workflow while learning.

Golden rules to remember

  • HTML = structure & meaning. CSS = appearance. Never use HTML tags purely to make text look a certain way — use CSS.
  • Always close your tags, always quote your attribute values.
  • One <h1> per page; headings should be in logical order (don't skip from h1 to h4).
  • Every <img> needs a meaningful alt.
  • Use classes for styling that repeats; use ids sparingly (mainly for JS hooks or single anchors).
  • Prefer Flexbox for one-dimensional layouts, Grid for two-dimensional layouts.
  • box-sizing: border-box on everything saves a lot of layout headaches.
  • Test responsively — resize the browser or use DevTools' device toolbar (Ctrl/Cmd+Shift+M).
